# To-Do List App

A simple HTML and CSS to-do list page. It includes a header, task input area, task summary cards, and three sample task rows with a checkbox on the left and a delete button on the right.

## Features

- Clean to-do list layout
- Task input field with an add button
- Summary cards for active, completed, and total tasks
- Sample task rows:
  - Welcome to your to-do list!
  - Click the checkbox to mark as complete
  - Hover to delete items
- Black checkbox icon on each task
- Red delete sign on each task

## How to Run

Open `Todo.html` in your browser.

No installation is required because this project uses plain HTML and CSS.

## Notes

The current version is a static page. The add task button, checkbox, and delete button are visible UI elements, but they do not yet have JavaScript functionality.
